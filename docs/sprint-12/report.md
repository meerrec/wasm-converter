захода: `docs/sprint-12/{oracle,budgets,audit,rc}.md` и диагнозы

**Аудиты (S4.1).** `docs/sprint-12/audit.md` (`e7db82a`): `cargo deny` и

**0,89**: высоты строк квантуются целым твипом, на разрыве страницы

## Отклонения от плана и спорные решения

- **SSIM двух таблиц — 0,89, не 0,95.** `long_table` 0,8921 и
  `long_table_header_repeat` 0,8938 подняты с 0,55–0,59 (S1.2/S1.3), порог не
  взят: остаточное расхождение — положение штриха границ (±0,24 pt), сдвиг
  текста по X (~4,4 твипа против буквы ECMA-376) и лишняя нижняя граница
  эталона (артефакт Writer'а). Диагноз — `docs/sprint-12/docx-tables.md`;
  исход, допустимый решением 1 плана. Третья таблица ниже порога —
  `cant_split_rows` 0,9382 (та же сетка причин).
- **XLSX: Ф2 — бэклог.** Четыре фикстуры класса «д» (печатная область LO
  шире видимых ячеек: `values-long-text`, `charts-five-kinds`,
  `images-over-data`, `layout-frozen-columns`) остаются после Ф1;
  рекомендуемые под-слайсы Ф2а–Ф2в — в `docs/sprint-12/xlsx-pagination.md`.
- **Бюджет `wasm (viewer)` 300 → 480 КБ.** Рост 287,31 → 464,2 КБ дал
  `b43a2de` (четыре поднабора Carlito, вшитые в основной модуль для
  превью — без них превью разъезжалось с PDF). Фикс легитимен, бюджет
  пересмотрен решением Спринта 12 (`82a84ee`, обоснование —
  `docs/sprint-12/budgets.md`); строка остаётся стражем с запасом 3 %.
- **×10–300 не подтверждён** — унаследовано от Спринта 11 (медиана ×5,3,
  `docs/bench-js.md`); бенч-отчёт + демо заменяют видео-демо «1M ячеек
  60 FPS» (решение 4 плана).
- **Firefox 96+ → 105+.** Реальный порог — OffscreenCanvas (105+);
  README исправлен (`74859dd`), ROADMAP §1 синхронизирован этим слайсом.
- **Fallback на main-thread не реализован.** Принцип 6 ROADMAP §3.3 остаётся
  целью: без OffscreenCanvas инициализация вьюера падает с ошибкой, а не
  подменяет транспорт. В v1.0.0 это зафиксировано как несделанное, не как
  non-goal.

## Что осталось незакрытым

- **XLSX Ф2** (4 фикстуры класса «д»): якоря диаграмм/рисунков и переполнение
  текста в печатной области — оценка ~200–400 строк по трём под-слайсам,
  риски разобраны в `docs/sprint-12/xlsx-pagination.md`.
- **Non-goal v1:** сноски/комментарии (разбор есть, раскладки нет),
  обтекание текстом вокруг плавающих рисунков (долг Спринта 9), VML-фолбэки
  (ADR-0014) — зафиксированы в README и ROADMAP.
- **TypeDoc:** генерация зелёная, но предупреждения о символах, не попавших
  в документацию (notExported), не добиты; на публикацию не влияют.
- **MSRV номинален.** lopdf 0.45.0 заявляет `rust-version = "1.88"` при
  workspace MSRV 1.82; резолвинг держит `.cargo/config.toml`
  (`incompatible-rust-versions = "fallback"`), но объявленный MSRV для
  крейта pdf формально неверен. Решение (поднять MSRV или зафиксировать
  оговорку) — после релиза.
- **Публикация (S4.3)** — после этого слайса: тег `v1.0.0` на `main`,
  джоба `publish` в `.github/workflows/release.yml`, GitHub Release.
