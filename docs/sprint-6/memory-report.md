# B4: память PDF-экспорта (Спринт 6)

Дата замера: 2026-10-06, macOS aarch64, Rust 1.98.0, release-сборка, ветка `sprint/6-basic-pdf`.

## Методика

Потоковой записи в printpdf 0.8.2 нет: `PdfExporter::export_xlsx_sheet` держит
весь `PdfDocument` (lopdf) в памяти до `save` и возвращает готовый `Vec<u8>`.
Мерится пиковая память процесса вокруг одного экспорта:

    cargo build --release -p doc-converter-pdf --example mem_probe
    /usr/bin/time -l target/release/examples/mem_probe <книга.xlsx>

`/usr/bin/time -l` печатает maximum resident set size (свой код для RSS требовал
бы `unsafe` или `/proc`, которого на macOS нет). `mem_probe` печатает размер
входа, размер PDF, число страниц и время; `--open-only` останавливается после
разбора книги, и разница пиков даёт вклад экспорта. Разброс повторов ≤ 0,2 МиБ
(96 страниц: 50,7 и 50,5 МиБ).

Коммитнутых фикстур на 100 страниц нет (максимум — `scale-ten-pages.xlsx`, 13
страниц), поэтому конец диапазона снят на временной книге в `/tmp`: 4600 строк
того же ряда (600 строк → 13 страниц, 4600 → 96), собранной тем же exceljs из
`scripts/gen-fixtures.ts`; в репозиторий не добавлена.

## Выводы

1. Память растёт линейно: ≈ 0,44 МиБ на страницу плюс ≈ 8 МиБ постоянной части
   (процесс, разобранная книга, шрифты). По отрезкам 2→13→42→96 страниц наклон
   держится в 0,41–0,45 МиБ/страница; прямая через все точки даёт
   RSS ≈ 8,3 + 0,44 × страниц, то есть на 100 страницах ожидается 50–55 МиБ.
2. Линейность ожидаема: `export_xlsx_sheet` не пишет в поток — lopdf копит все
   объекты страниц, а `save` сериализует их в `Vec<u8>`. В памяти документ
   (~450 КиБ/страница) в 13 раз больше файла (~35 КиБ/страница).
3. OOM-риска на типичных книгах нет: 100 страниц ≈ 55 МиБ в нативном процессе.
   Оговорка: замер нативный (macOS, release), не wasm: в браузере документ живёт
   в линейной памяти wasm32, числа будут того же порядка, но точных wasm-цифр
   нет — их снимет Playwright вместе с кнопкой экспорта (B6).
4. Ограничение принято осознанно: на 1000 страницах экстраполяция даёт ~450 МиБ,
   что рискованно для воркера на памяти-ограниченном мобильном устройстве.
   Спринт 7 (стриминг) снимет множитель «на страницу»: пик станет O(страница),
   а не O(книга). До этого большие книги — известный предел (ADR-0008).
