# Эпик F — тесты

- Спринт 6 «Базовый PDF» · ветка `sprint/6-basic-pdf`
- Коммиты: 1a06421 (фикстуры), 771a6b0 (перенос), 5411d00 (внешние проверки)

## Что сделано

**F1. Совпадение точек переноса** (`crates/pdf/tests/export.rs:504`,
`pdf_wraps_text_exactly_like_canvas`). Тест берёт последовательность строк из
DisplayList (canvas-путь) и из PDF — прогоны `Tj`, раскодированные по
ToUnicode — и сравнивает их. Тест проверен на падение: кегль ×1.05 ломает
совпадение на одной букве; после проверки правка откачена.

**F2. Фикстуры** (`scripts/gen-fixtures.ts`, 1a06421):

- `text-cyrillic-wrap.xlsx` — кириллица («Привет, мир», «ё Ё Ђ ћ №5»),
  перенос, обрезка `#####`, узкая колонка;
- `scale-1000-cells.xlsx` — ровно 1000 ячеек (бюджет размера);
- `scale-ten-pages.xlsx` — 600 строк → 13 страниц (бюджет времени).

Генератор обновлён, `test-fixtures/xlsx/oracle.json` пересобран — 113 фикстур.

**F3. Внешние проверки** (`crates/pdf/tests/external.rs`, 5411d00):
`qpdf_check_accepts_exported_pdfs` (код 0, без error в stderr) и
`pdftotext_extracts_cyrillic` (ищет «Привет, мир», «ё», «Ђ», «№»). Утилит
локально нет — тесты пропускаются с сообщением; `#[ignore]` намеренно не
используется, чтобы CI-прогон не терял их молча.

**F4. Чек-лист DoD в PR #11** — ведёт оркестратор; на момент отчёта 🔄.

## Отклонения от плана

- F3 локально не выполняется: `qpdf` и `poppler-utils` есть только в CI
  (шаг установки в rust-джобе). Решение архитектора — не тащить бинарные
  утилиты в dev-окружение.
- F1 живёт в `crates/pdf/tests/export.rs`, а не в `crates/xlsx`: сравнивать
  приходится уже собранный PDF, а не промежуточную раскладку.
- F4 не закрыт на момент отчёта — чек-лист DoD заполняется в PR #11
  оркестратором, не субагентом.
