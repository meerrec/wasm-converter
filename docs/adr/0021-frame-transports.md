# ADR-0021: Два транспорта кадра — SAB и ArrayBuffer

**Статус:** Принято
**Дата:** 12.10.2026
**Контекст:** Спринт 11, пункты 1–2 («оба пути», «transferable везде»)
**Связанные ADR:** ADR-0003 (граница `render`)

---

## Контекст

Кадр собирается в Web Worker'е и рисуется painter'ом из `SharedArrayBuffer`
(кольцо из двух слотов). `SharedArrayBuffer` существует на странице только при
cross-origin isolation — заголовках `Cross-Origin-Opener-Policy: same-origin`
и `Cross-Origin-Embedder-Policy: require-corp`. Их ставит тот, кто отдаёт
**страницу**, а при embed это часто не под контролем потребителя: iframe на
чужом сайте, расширение, Electron/webview, GitHub Pages.

До Спринта 11 путь без SAB был аварийным: `paint_display_list_bytes`
(копия кадра) и `docx_build_display_list` — «чтобы хоть как-то работало».
Формулировка роадмапа — «first-class путь без SAB: тот же API» и
«путь без SAB работает без деградации функциональности».

## Решение

1. **Оба транспорта равноправны.** `sab` (кольцо в `SharedArrayBuffer`) и
   `bytes` (два `ArrayBuffer`, которые воркер заполняет по очереди) дают один и
   тот же API, один и тот же кадр (собирает одна функция Rust) и один и тот же
   painter. Отличается транспорт, а не поведение.
2. **Двойная буферизация — в обоих.** В пути `bytes` буфер возвращается в
   воркер transfer'ом, а не аллоцируется заново на кадр; глубина — два кадра,
   как у кольца.
3. **Выбор автоматический, но управляемый.** По умолчанию `transport: 'auto'`:
   есть `crossOriginIsolated` — SAB, нет — `bytes`. Явный
   `transport: 'sab'` без заголовков — ошибка инициализации, а не тихая
   подмена: потребитель, которому важна нулевая копия, обязан узнать, что её
   не будет. Выбранный путь виден в `viewer.transport`.
4. **Бюджеты производительности фиксируются отдельно** для обоих путей
   (`ROADMAP.md` §9): числа пути `bytes` не прячутся за числами SAB.

## Альтернативы

- **Только SAB** — отвергнуто: требует заголовков, которые потребитель не
  всегда может поставить; просмотрщик перестал бы работать при embed.
- **Только `bytes`** — отвергнуто: теряется zero-copy на каждом кадре, а
  прокрутка больших листов — целевой сценарий проекта.
- **Автовыбор без явной опции** — отвергнуто: молчаливая деградация
  неотличима от ошибки настройки заголовков.

## Последствия

- README документирует COOP/COEP и то, что даёт SAB (и что теряется без него).
- Тесты гоняют оба пути; путь `bytes` покрыт и в `packages/core`
  (`frame_transport.spec.ts`), и в сквозных тестах вьюеров.
- Если в будущем появится третий транспорт (например, `WebTransport` между
  окнами), он встаёт в тот же интерфейс выбора, а не в обход него.
