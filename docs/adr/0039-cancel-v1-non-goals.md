# ADR-0039: Отмена non-goal'ов v1, противоречащих целевой архитектуре

**Статус:** Принято
**Дата:** 21.10.2026
**Контекст:** `docs/architecture.md` — архитектурный аудит и роадмап
миграции; эпик «отмена non-goal'ов» фазы 1 аудита
**Связанные ADR:** [ADR-0016](0016-docx-error-policy.md) (политика ошибок),
[ADR-0017](0017-strict-vs-transitional.md) (пересматривается ADR-0034),
[ADR-0027](0027-npmjs-primary-registry.md) (реестры npm)

---

## Контекст

- To-Be-матрица `docs/architecture.md` требует форматы сверх DOCX/XLSX
  (PPTX, ODF) и Strict OOXML, а §1.9 документа перечисляет как ограничения
  v1.0.0: Strict OOXML, PPTX, XLSB, `.docm`, зашифрованные и бинарные
  `.doc`.
- Часть этих ограничений объявлена non-goal'ами v1 в живых документах
  (`ROADMAP.md` §2, `AGENTS.md`, `README.md`) и в ADR-0017. Non-goal — это
  архитектурное решение, а не «пока не сделано»: оно запрещает планировать
  работу. Роадмап миграции из аудита такую работу требует.
- Редактирование, коллаборация, ИИ-предложения, server-side и real-time
  (`ROADMAP.md` §2) аудитом не затрагиваются — их non-goal-статус вне
  предмета этого решения.

## Решение

1. **Отменяются** non-goal-статусы v1, противоречащие To-Be аудита: PPTX,
   XLSB (`ROADMAP.md` §2), Strict OOXML (пересмотр ADR-0017 — новым ADR,
   ADR-0034), `.docm`, зашифрованные документы, бинарный `.doc`
   (`docs/architecture.md` §1.9).
2. **Реализация планируется** только там, где её требует To-Be: PPTX
   (ADR-0033), Strict OOXML для DOCX и XLSX (ADR-0034), ODF
   `.odt`/`.ods`/`.odp` (ADR-0036; в аудите явно не назван — включён как
   строка матрицы «Форматы → ODF»), `.docm`. Это задачи Эпика 3 роадмапа.
3. **XLSB, шифрование и бинарный `.doc`** — статус non-goal снят, но задач в
   плане нет: To-Be их не содержит. Их состояние — «не реализовано», а не
   «non-goal»; текущее поведение (фатальная ошибка при открытии)
   сохраняется до отдельного решения о поддержке.
4. **Не отменяются:** редактирование, коллаборация, ИИ-предложения,
   server-side, real-time (`ROADMAP.md` §2) — их non-goal-статус остаётся в
   силе.

## Последствия

- `ROADMAP.md` §2, `AGENTS.md` (скоуп), `README.md` (ограничения v1)
  переписаны: PPTX/XLSB убраны из «не делаем», Strict — из «только
  Transitional», `.docm`/шифрование/`.doc` помечены снятым статусом.
- Поведение кода до задач Эпика 3 не меняется: Strict по-прежнему
  отклоняется (`Error::StrictNotSupported`), `.docm` — фатальная ошибка.
  Поддержка появляется в соответствующих задачах, а не этим решением.
- Пересмотр технического содержания ADR-0017 — отдельный ADR-0034; этот ADR
  отменяет только статус non-goal'а.
