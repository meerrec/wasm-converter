## Что сделано

### 1. Модульная структура `docx/src/layout/`

Создана полная модульная структура для раскладки DOCX:

| Модуль | Статус | Описание |
|--------|--------|----------|
| `engine.rs` | ✅ Готово | Центральный движок раскладки: `layout_document()`, `PageLayout`, `LayoutState`, `LayoutOptions` |
| `line_break.rs` | ✅ Готово | Разбивка строк с использованием `render::text_measure` (ADR-0005) |
| `pagination.rs` | ✅ Готово | Пагинация: `Paginator`, `MarginsLayout`, обработка разрывов |
| `tables.rs` | ✅ Готово | Раскладка таблиц: `compute_column_widths()`, `compute_row_heights()` |
| `float.rs` | ✅ **НОВЫЙ** | Плавающие элементы: позиционирование `wp:anchor`, обработка `RelFromH`/`RelFromV` |
| `mod.rs` | ✅ Готово | Экспорт всех типов и функций |

### 2. Интеграция с `render::text_measure`

- ✅ `LineBreaker` использует `render::text_measure::measure_text()` и `break_lines()`
- ✅ Единая логика измерения текста для DOCX и XLSX
- ✅ Поддержка переноса строк с учётом ширины страницы

### 3. Основные функции

#### `layout_document()`
```rust
pub fn layout_document(
    document: &Document,
    options: &LayoutOptions,
    fonts: &mut FontRegistry,
) -> Result<PageLayout, LayoutError>
```

- ✅ Обработка абзацев с разбивкой на строки
- ✅ Обработка таблиц
- ✅ Обработка разрывов секций
- ✅ Автоматическая пагинация
- ✅ Поддержка нескольких секций

#### `layout_paragraph()`
- ✅ Сбор текста из всех run
- ✅ Разбивка на строки через `LineBreaker`
- ✅ Измерение ширины каждой строки
- ✅ Возврат `Vec<LayoutItem>` с позициями

### 4. Модуль `float.rs` — Плавающие элементы

Полная реализация позиционирования плавающих элементов:

**Поддерживаемые базы отсчёта (RelFromH/RelFromV):**
- ✅ `LeftMargin`, `RightMargin`
- ✅ `Page` (центр страницы)
- ✅ `Margin` (текущая позиция в тексте)
- ✅ `Character` (относительно символа)
- ✅ `InsideMargin`, `OutsideMargin`
- ✅ `Column` (для многоколоночной раскладки)
- ✅ `Paragraph`, `Line` (для вертикального позиционирования)

**Функции:**
- ✅ `layout_float()` — раскладка одного плавающего элемента
- ✅ `layout_floats_on_page()` — раскладка всех floats на странице
- ✅ `create_float_context()` — создание контекста раскладки
- ✅ `emu_to_px()`, `twips_to_px()`, `half_points_to_px()` — преобразование единиц
