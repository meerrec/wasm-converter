Релиз 2.1.0: четыре ленивых wasm-модуля (XLSB, ODS, ODT, ODP) с фабриками
`createXlsbViewer`/`createOdsViewer`/`createOdtViewer`/`createOdpViewer`,
контракт `FormatPlugin`, единый путь исполнения кадра (ADR-0044), единая
диагностика (ADR-0045) и поштучная отправка потока в wasm без ожидания
ленивого модуля (ADR-0049). Версии всех четырнадцати npm-пакетов и крейтов
подняты релизным коммитом; публикация по тегу `v2.1.0`.
