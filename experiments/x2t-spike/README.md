# Харнесс спайка x2t (ONLYOFFICE → WASM)

Страница с настоящей конвертацией форматов: файл выбирается в `<input type=file>`, уходит в
classic-воркер, там живёт модуль x2t и MEMFS, назад приезжают байты выхода, код возврата `main`
и stderr. Показываются метрики, предпросмотр (записи zip / текст / hex) и ссылка на скачивание.

Типизированная обвязка и сами артефакты — в пакете `packages/x2t` (`@doc-converter/x2t`,
`vendor/x2t.js` + `vendor/x2t.wasm`, Git LFS). Харнесс лежит вне pnpm-workspace и подключает
пакет относительным путём `../../packages/x2t/src/index.js`, а статику берёт из
`packages/x2t/vendor` через `publicDir` — копий артефактов в репозитории нет.

## Запуск

```bash
pnpm -C experiments/x2t-spike install          # свои node_modules: каталог вне workspace
pnpm -C experiments/x2t-spike dev              # страница на порту из vite.config.ts
node experiments/x2t-spike/tools/preview-check.mjs
```

`tools/preview-check.mjs` — приёмка через Playwright: поднимает страницу (переиспользует уже
запущенный dev-сервер с того же порта, иначе поднимает свой и гасит за собой), ждёт готовности
модуля и на фикстуре `test-fixtures/docx/styles/doc_defaults.docx` прогоняет docx → odt
(выход обязан быть zip с записью `mimetype`), docx → txt (непустой выход) и попытку docx → pdf.
Печатает время подъёма, время и размер каждой конвертации, память (`performance.memory`, если
браузер её отдаёт) и исход pdf; выходы и `preview-check.json` кладёт в `/tmp/x2t-preview-check`.
Проверка pdf приёмку не валит: движка раскладки в сборке нет, и оба известных исхода — «pdf нет».
Playwright скрипт берёт из `examples/viewer` — там стоят браузеры под свою версию, а у копии
харнесса их в кэше может не быть. Переопределения: `X2T_URL`, `X2T_PORT`, `X2T_OUT`, `X2T_TIMEOUT`.

**Браузерный прогон выполняет координатор**: в окружении субагента исполнение стороннего wasm
запрещено, поэтому здесь проверены только `tsc --noEmit` и `vite build`.

## Что известно из прогона в Node (в браузере не перепроверялось)

- docx → odt работает: мелкая фикстура — 19 мс и 3424 Б; реальный документ 5,9 МБ — 1,44 с и 2,8 МБ.
- docx → txt работает, но на реальном документе текст выходит **не в UTF-8** (русский бьётся) —
  похоже, не выставлен `m_nCsvTxtEncoding` в `params.xml`. Открытый вопрос, править — в пакете.
