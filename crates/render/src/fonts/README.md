# Шрифты Carlito

Источник — официальный репозиторий [googlefonts/carlito](https://github.com/googlefonts/carlito),
каталог `fonts/ttf/`, версия шрифта 1.104 (коммит пришпилен в скрипте подрезки).
Лицензия — SIL Open Font License 1.1; файл `OFL.txt` обязан лежать рядом с
шрифтами, это требование лицензии.

| Файл | Начертание | Размер |
|---|---|---|
| `carlito-subset.ttf` | Regular | 87 КБ |
| `carlito-bold-subset.ttf` | Bold | 91 КБ |
| `carlito-italic-subset.ttf` | Italic | 86 КБ |
| `carlito-bolditalic-subset.ttf` | Bold Italic | 106 КБ |

Подрезаны через `pyftsubset` (fontTools, версия пришпилена) без хинтинга:
465 кодпоинтов на файл — ASCII, Latin-1 Supplement (кроме soft hyphen),
кириллица U+0400–U+04FF (254 кодпоинта; U+0476 и U+0487 в Carlito отсутствуют),
тире и кавычки U+2012–U+2022, многоточие, €, № (U+2116) и ™.

Пересобрать: `bash scripts/subset-fonts.sh` (нужен `uv`). Скрипт скачивает
полные шрифты во временный каталог, сверяет контрольные суммы, подрезает все
четыре начертания и проверяет, что набор кодпоинтов совпал с ожидаемым;
повторный запуск даёт байт в байт тот же результат. Advance-метрики Regular
обязаны совпадать с прежним подрезанным файлом — набор символов расширяется
только добавлением новых кодпоинтов.
